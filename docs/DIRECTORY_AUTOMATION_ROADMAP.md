# nowbuild后续需求

## 目标

在不保存第三方账号密码、不自动确认付费或最终提交的前提下，减少用户准备素材、填写目录表单和跟踪结果的重复工作。

## 需求一：插件自动采集 Launch Kit 素材

### 用户场景

用户建立 Campaign 后，插件从产品官网获取可用于目录提交的品牌素材，并在 Launch Kit 中供用户确认、替换或删除。

### 功能范围

- 从官网结构化数据、`apple-touch-icon` 和 favicon 中寻找 Logo。
- 读取 `og:image` 和 `twitter:image` 作为产品图片候选。
- 当官网没有合适图片时，由插件截取产品首页首屏。
- 校验图片格式、尺寸、文件大小和可访问性。
- 在 Launch Kit 中展示来源和预览，由用户最终确认。
- 抓取失败时保留现有手动上传入口。
- 用户确认后的素材可直接注入支持的 Directory 表单。

### 安全边界

- 只读取用户明确提供的产品官网及其公开资源。
- 不读取登录后页面、浏览器历史或无关标签页。
- 不自动把未确认的图片提交给第三方。
- 不绕过验证码、登录验证、付费或网站访问限制。

### 验收标准

- 能为大多数带标准 Metadata 的官网识别 Logo 和 OG 图片。
- 没有 OG 图片时可生成一张首屏截图候选。
- 用户可以确认、替换、删除素材。
- 保存后的素材能被目录辅助填写流程读取。

## 需求二：Directories 自动化能力扩展

### 当前基线

- 从 100+ 候选目录中进行产品匹配和排序。
- 当前 19 个目录具备插件辅助填写流程。
- 用户负责登录、验证码、付费判断和最终提交。
- 提交、审核、上线、拒绝等状态由用户手动回填。

### 后续功能

- 持续核验候选目录的真实入口、费用、流量价值和提交条件。
- 将高价值目录按“已支持、部分支持、人工提交、不建议提交”分类。
- 优先扩展 Product Hunt、BetaList、AlternativeTo、SaaSHub 等高价值目录。
- 复用已确认的 Launch Kit，在多页面表单中逐阶段填写和续跑。
- 在登录、验证码、企业邮箱、徽章、付费和最终提交前安全暂停。
- 记录字段失效、入口变化和平台阻塞，便于更新适配器。
- 条件允许时读取公开的审核或上线结果；无法可靠读取时继续使用人工回填。
- 自动化支持数量必须从统一配置读取，避免产品文案与实际能力不一致。

### 验收标准

- 每个标记为“插件辅助”的目录都有真实页面测试记录。
- 插件能够从 NowBuild 页面直接唤起目标目录流程。
- 必填资料缺失时先引导用户补充 Launch Kit。
- 表单填写后始终停在最终提交、付款或不可逆操作之前。
- 目录状态和证明链接可以在 Pipeline 中持续维护。

## 建议优先级

1. 官网 Logo 与 OG 图片采集。
2. Launch Kit 缺失素材检查。
3. 高价值目录适配器扩展与回归测试。
4. 官网首屏截图兜底。
5. 审核和上线结果的公开信息验证。
