# 陪伴式英语剧情游戏 PRD

**版本**：v0.3  
**状态**：讨论稿  
**首发市场**：中国、日本、韩国  
**首发人群**：18 岁以上、希望提升旅行英语的男性用户

## 1. 产品定义

用户为固定女主角定制声音，与这个“始终差一步才能得到的人”共同经历连续恋爱剧情，并通过英语听、说、读、写推动故事发展。

核心价值：

- 角色关系提供持续动力；
- 连续剧情提供真实语言环境；
- 英语是解决问题、改变剧情和表达感情的游戏操作；
- 用户因为想知道两个人最终会怎样而持续学习。

## 2. 产品原则

1. 先有剧情目标，再出现学习任务。
2. 角色负责陪伴，系统负责中文提示和纠错。
3. 失败不阻断剧情，角色可以救场。
4. 情感选择影响关系；英语表现影响隐藏内容和能力成长。
5. 每次只纠正 1～2 个最影响理解的问题。
6. 所有主要角色明确成年；亲密内容双方自愿、非露骨。

## 3. 固定女主角

女主角暂定名为 **Lena**，27 岁，亚洲背景，曾在美国学习和工作，英语流利。

- 外表冷静，实际温柔；
- 聪明独立，有自己的事业和选择；
- 会有分寸地调情，但不会轻易确认关系；
- 欣赏可靠、真诚、愿意成长的人；
- 习惯独自承担问题，不擅长承诺和求助；
- 对用户明显特殊，却总在关系即将确定时保留一步。

核心矛盾：她喜欢用户，但不愿为了感情放弃自我。用户需要成长为能与她并肩的人。

## 4. 声音定制

- 用户上传音频；
- 通过 Fish Audio 等第三方服务完成声音克隆和语音生成；
- 用于剧情对白、来电、聊天语音和自由对话；
- 用户声明拥有授权；声音默认私有；支持投诉和删除。

## 5. 角色语言规则

- Lena 的语音、消息和剧情对白以英文为主；
- 她能理解中文，但通常用英文回应；
- 中文翻译由系统浮层提供，默认折叠；
- 用户说中文时，系统可转换成英文建议，但需要重新表达一次；
- 允许一键显示中文，避免卡关。

提示分三级：

1. 中文沟通目标；
2. 英文关键词和句型骨架；
3. 完整英文示例。

## 6. 核心体验闭环

```text
角色联系用户
→ 进入剧情事件
→ 阅读或听懂英文信息
→ 用英语完成行动
→ NPC 和角色自然回应
→ 剧情与关系发生变化
→ 获得语音、回忆或物品
→ 学过的表达在后续剧情重新出现
```

单次体验 5～10 分钟；同时提供 1～3 分钟的语音消息和短事件。

## 7. 页面与交互设计

### 7.1 MVP 表现形式

采用“文字乙游 + 静态 AI 场景图 + 角色语音”，暂不做 Live2D 和复杂 3D。

- 70%：文字、语音和静态剧情图；
- 20%：剧情选择、物品阅读和聊天；
- 10%：必须说或写英语完成的关键行动。

每章使用 4～6 张统一角色形象的竖屏图片。前端通过缩放、横移、景深、粒子、渐变、打字效果和语音波形增强沉浸感。

### 7.2 主要页面

| 页面 | 呈现 | 操作 |
|---|---|---|
| 首页·她的房间 | 角色场景图、未读消息、当前关系 | 听语音、继续剧情、进入聊天 |
| 章节地图 | 旅行路线、章节和回忆完成度 | 选择主线、支线或复习事件 |
| 视觉小说页 | 全屏场景图、对白框、角色语音 | 推进、自动播放、翻译、选择 |
| 语音行动页 | 沟通目标、提示、按住说话 | 录音、重说、提交 |
| 手机聊天页 | 文字和语音气泡 | 阅读、选择回复、自由输入 |
| 场景物品页 | 登机牌、菜单、地图、订单 | 找信息、完成阅读任务 |
| 章节结算页 | 回忆图、一句反馈、下章悬念 | 收藏、复习、继续 |
| 回忆馆 | 照片、语音、短信、物品 | 重看、重听、复习 |

### 7.3 分支结构

采用低成本的“短分支、主线汇合”结构：

```text
共同剧情 → 2～3 个选择 → 不同反应或短场景 → 回到共同主线
```

三类选择：

- 情感选择：影响 Lena 的态度和关系值；
- 行动选择：影响解决方式和场景顺序；
- 英语行动：影响 NPC 反馈、隐藏对白和学习评价。

普通选择可以显示中文；重要剧情必须使用自由语音或自由文字。

### 7.4 AI 图片规则

- 固定人物参考图、服装表、色板和面部特征；
- 日常对白复用背景，关键节点生成奖励 CG；
- 菜单、订单、路牌等准确文字由前端绘制；
- 同一图片通过裁切、滤镜和局部动效复用；
- 亲密场景采用氛围和转场，不制作露骨画面。

## 8. 第一季：《纽约七日，关系未定》

### 8.1 故事前提

用户和 Lena 认识半年，关系一直没有说破。她邀请用户陪自己去纽约参加好友婚礼。

她没有告诉用户：自己同时收到了一份美国工作邀请，旅行结束前需要决定是否留下。她邀请用户，是想知道两个人是否存在共同未来。

第一季结束时，两人确认彼此重要，但 Lena 仍未决定是否留在美国。

### 8.2 关系曲线

```text
期待出发 → 互相依赖 → 暧昧升温 → 进入朋友圈
→ 隐瞒引发冲突 → 危机中靠近 → 发生亲密关系
→ 感情确认但未来未定
```

### 8.3 章节与学习大纲

| 章节 | 剧情 | 学习能力 | 用户行动 |
|---|---|---|---|
| 序章：一起出发 | 找到 Lena 并赶上航班 | 航班号、时间、登机口、地点 | 读登机牌；说明位置；通知登机口变化 |
| 1. 入境考验 | 用户独自接受入境询问 | 旅行目的、停留时间、住宿地址 | 听懂并回答入境问题 |
| 2. 丢失的行李 | Lena 的行李没有到达 | 颜色、尺寸、材质、物品和进度 | 报告行李；填写表格；记录编号 |
| 3. 坐错地铁 | 两人迷路并发生小分歧 | 线路、换乘、出口、问路 | 向路人问路并解释路线 |
| 4. 酒店只有一间房 | 订单出错，只剩大床房 | 核对预订、投诉、换房和加床 | 阅读订单并与前台协商 |
| 5. 不是约会的约会 | Lena 让用户选择餐厅 | 菜单、点餐、配料、喜好和感受 | 点餐；处理错菜；回应暧昧问题 |
| 6. 她的朋友圈 | 朋友追问两人的关系 | 自我介绍、寒暄、兴趣和邀请 | 加入多人对话；写婚礼祝福卡 |
| 7. 她隐藏的决定 | Lena 坦白美国工作邀请 | 原因、失望、可能性和未来 | 不靠选项自由表达情绪 |
| 8. 纽约走散 | 两人在雨夜失联 | 电话、位置、地图和路线 | 用语音定位彼此并发送指令 |
| 9. 婚礼之夜 | 用户临时发言，关系越过暧昧边界 | 祝福、故事、社交和感受 | 30～60 秒祝酒；表达意愿和边界 |
| 终章：机场之前 | Lena 拒绝仓促决定未来 | 总结经历、关系期待和计划 | 录制 60 秒语音或写英文信 |

## 9. 序章详细规格：《一起出发》

### 9.1 目标

- 时长：8～10 分钟；
- 剧情目标：在机场找到 Lena，与她一起登机；
- 情感目标：建立“她一直在等，却不会承认”的暧昧感；
- 教学目标：完成第一次读、听、说、写闭环；
- 产品目标：无感完成水平初测和交互教学。

本章语言：

- `Where are you?`
- `I'm at...`
- `I'll meet you at Gate...`
- `The gate has changed to...`
- `Could you say that again?`

### 9.2 美术与声音资产

| 资产 | 用途 |
|---|---|
| 机场出发大厅 | 开场、值机和阅读任务 |
| Lena 在登机口等候 | 聊天、来电和选择 |
| Lena 靠近整理衣领 | 第一次身体暧昧 |
| 两人在落地窗前的 CG | 章节完成奖励 |
| 航班屏、登机牌、聊天界面 | 前端绘制准确信息 |
| 广播、环境音、提示音 | 建立机场氛围 |

### 9.3 逐屏交互脚本

| 节点 | 画面与交互 | 剧情和对白 | 学习行为 |
|---|---|---|---|
| P00 | 黑屏、广播、手机震动 | Lena：`You're not going to make me fly to New York alone, are you?` | 英文字幕；翻译折叠 |
| P01 | 机场大厅 | 系统：“在登机前找到 Lena。” | 教用户推进剧情 |
| P02 | 手机聊天 | `Where are you? Boarding starts in thirty minutes.` | 重听语音 |
| P03 | 三项选择 | 她在问什么？ | 完成首次听力理解 |
| P04 | 值机柜台、按住说话 | 工作人员：`Are you checking any bags?` | 回答 `Yes, one bag.` 或 `No, just this carry-on.` |
| P05 | 登机牌 | Flight NA217；Gate C23；Boarding 10:40 | 找到登机口和时间 |
| P06 | 聊天输入框 | 告诉 Lena 自己在安检，十分钟后见 | 输入或朗读 `I'm at security. I'll meet you in ten minutes.` |
| P07 | Lena 等候图 | `Ten minutes? I've heard that before.` | 选择可靠、暧昧或对抗回复 |
| P08 | 航班屏、广播 | `The departure gate has changed from C23 to C31.` | 重听或请求重复 |
| P09 | 多个航班信息 | 新登机口在哪里？ | 选择 C31 |
| P10 | 语音或文字输入 | 马上告诉 Lena 登机口变更 | `The gate has changed to C31. I'll meet you there.` |
| P11 | Lena 在 C31 等候 | `You found me. I thought I'd have to come get you.` | 根据前面选择显示不同回应 |
| P12 | 整理衣领近景 | `Try not to get lost when we land.` | 选择主动、独立或调侃表达 |
| P13 | Lena 手机短暂亮起 | `Next Steps — New York Office` | 埋下工作邀请伏笔 |
| P14 | 落地窗奖励 CG | `Come on. Our story starts at Gate C31.` | 解锁回忆和第一章预告 |

### 9.4 关键选择

P07：

- `I'm sorry. I'm coming now.` → 可靠型回应；
- `You missed me already?` → 暧昧型回应；
- `Save the lecture until I get there.` → 对抗型回应。

P12：

- `Then stay close.` → 主动亲密倾向；
- `I can handle it.` → 独立可靠倾向；
- `You'd come looking for me.` → 调侃暧昧倾向。

选择只改变短对白和用户偏好标签，主线重新汇合。

### 9.5 学习评价与兜底

序章不显示分数，只显示：“你成功找到 Lena，并完成登机。”

后台记录：

- 是否听懂位置问题；
- 能否从登机牌找到时间和登机口；
- 是否能表达行李数量；
- 是否借助提示说明位置；
- 是否听懂登机口变化；
- 重听、重说和提示次数。

失败兜底：

1. 第一次失败：高亮关键词；
2. 第二次失败：显示句型骨架；
3. 第三次失败：播放完整示范，跟读即可推进；
4. 识别异常时允许文字输入；
5. 不扣关系值，不改变 Lena 的基本态度。

章节结算：

- 完成能力：看懂登机口、说明位置、通知航班变化；
- 记住一句：`The gate has changed to C31.`；
- 下章悬念：`Can you handle immigration without her?`

## 10. 长线故事

采用“有限主爱情线 + 无限旅行篇”：前四季完成从暧昧到恋人的主线；第五季以后，两人以恋人身份持续旅行。

| 季 | 地点 | 关系阶段 | 学习阶段 |
|---|---|---|---|
| 第一季《纽约七日》 | 纽约 | 确认心意但没有名分 | 旅行生存英语 |
| 第二季《沿海公路，禁止承诺》 | 加州 | 像恋人一样旅行但不承诺 | 交通、住宿和突发问题 |
| 第三季《三十天临时生活》 | 旧金山 | 短期同居，最亲密也最不稳定 | 长住生活、服务和深度社交 |
| 第四季《最后一程》 | 美国西北线 | 两人以为这是告别旅行 | 独立规划、复杂应变和综合表达 |
| 第五季起《和你去世界》 | 全球城市 | 稳定恋爱 | 城市主题和进阶英语 |

### 10.1 第二季学习章节

1. 转机和航班变更；
2. 租车、保险和合同；
3. 导航、路况、加油和停车；
4. 车辆故障与道路救援；
5. 临时订房、价格和投诉；
6. 配料、过敏和换餐；
7. 尺码、试穿、付款和退换；
8. 预约、购票和导览；
9. 交通检查与证件说明；
10. 比较利弊、提出和拒绝建议。

### 10.2 第三季学习章节

1. 房屋、押金和设施问题；
2. 超市、数量、预算和偏好；
3. 外卖错单、退款和补送；
4. 电话卡、网络和套餐；
5. 聚会社交和礼貌离场；
6. 症状、药房和诊所预约；
7. 道歉、解释和社区规则；
8. 报警、护照和领事协助；
9. 澄清误会、表达需求和边界；
10. 决定、理解和远距离关系。

### 10.3 第四季学习章节

1. 搜索信息、规划行程和说明理由；
2. 改签、退款和协调时间；
3. 与陌生人开启话题和讲故事；
4. 天气警报、安全指令和风险；
5. 核对账单、举证和协商；
6. 追问、转述和表达理解；
7. 独立完成交通、餐饮和住宿；
8. 同时处理多个旅行问题；
9. 长对话解释误会和真实计划；
10. 2～3 分钟综合表达，正式确认关系。

第五季后使用城市模板持续生产：

```text
城市愿望 → 文化体验 → 现实问题 → 关系冲突
→ 突发事件 → 共同解决 → 城市回忆 → 下一站
```

## 11. 学习机制

### 11.1 单场景模板

```text
剧情刺激 → 英文输入 → 理解行动 → 表达准备
→ 用户输出 → NPC 自然回应 → 剧情结果
→ 轻量复盘 → 后续剧情再次出现
```

### 11.2 能力进阶

```text
完整句跟读 → 关键词替换 → 只给沟通目标
→ 自由对话 → 语速、口音和突发情况
```

### 11.3 复习

系统记录用户没听懂、说不清、过度依赖提示和即将遗忘的表达，并重新写入后续剧情，而不是单独刷题。

## 12. 游戏化系统

- 关系值：由情感选择、尊重和行动决定；
- 信任值：决定角色分享秘密和未来计划；
- 英语能力：听、说、读、写和场景熟练度；
- 回忆收集：照片、语音、短信和旅行物品。

奖励包括专属语音、隐藏对白、旅行照片、共同物品、支线约会和下一季线索。

## 13. 亲密内容

- 第一季设置 2～3 次身体暧昧、1 次可选亲密事件；
- 使用亲吻、拥抱、同床后的清晨和转场等表达；
- 用户可关闭亲密内容；
- 英语成绩不直接兑换亲密行为；
- 学习重点是确认意愿、表达边界、感受和关系期待。

## 14. MVP

1. 固定女主角与声音定制；
2. 第三方语音克隆和流式合成；
3. 静态 AI 场景图、文字、语音和轻动效；
4. 视觉小说、聊天、语音行动和场景物品；
5. 第一季 9 个主章节，加序章和终章；
6. 英文、折叠中文和三级提示；
7. 短分支、关系值和回忆收集；
8. 发音、理解和表达反馈；
9. 学习档案与剧情式复习；
10. 日常语音消息和简单自由聊天；
11. 年龄确认、亲密内容开关和数据删除。

暂不包含：开放世界、多人社交、复杂 3D、公开剧情创作和声音交易。
