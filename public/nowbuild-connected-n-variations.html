NowBuild / Connected N

Transparent mark · no container
01Balanced Signature

平衡版：轻微起伏，N 的骨架清晰，连接感自然。

02Forward Script

前倾版：保留 F 的速度感，但轮廓改为连续手写。

03Low Sweep

低位长起笔：更像签名，左侧进入动作更明显。

04High Exit

高位收笔：右上端略微上扬，整体更轻、更灵动。

05Compact Bold

紧凑粗笔：适合 favicon 和 App 导航，小尺寸最稳定。

06Wide Air

宽幅细笔：留白更充足，偏高端、编辑感与设计工具气质。

07Signal Thread

信号线版：只把贯穿中心的一小段变为品牌色，不添加装饰。

08Soft Loop

柔弧版：转角完全消失，像一段连续呼吸的笔迹。

09Calligraphic Tail

书写收锋：用第二条细尾制造笔压变化，更接近真实签名。

10Pure Monoline

纯单线版：没有强调色和附加笔画，最克制、最易延展。
